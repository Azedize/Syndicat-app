---
name: Public trust content
description: Rules for keeping public product presentation honest when operational data is not available.
---

The public product presentation is presentation-only unless a real, explicitly scoped public data contract exists. Do not show operational KPIs, charts, customer testimonials, named organizations, or outcome claims that are not backed by verifiable source data.

**Why:** Public-facing proof can be mistaken for actual customer or platform performance, which conflicts with the database-as-source-of-truth requirement and weakens user trust.

**How to apply:** Use descriptive capability language and semantic visual cues on public landing routes. If quantified proof is later added, load it from a documented API source and make its freshness and scope explicit.
