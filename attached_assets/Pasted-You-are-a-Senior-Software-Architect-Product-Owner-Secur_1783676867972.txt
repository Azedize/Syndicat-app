SUPER ADMIN ROLE
=================================================

Super Admin represents the platform owner.

He must be able to:

✓ Create Syndicates
✓ Suspend Syndicates
✓ Activate Syndicates
✓ Manage subscriptions
✓ Manage platform billing

✓ View all buildings
✓ View platform analytics
✓ View platform revenue
✓ View support tickets
✓ Manage platform settings
✓ Access audit logs

Super Admin must NOT manage daily building operations.

He may only access a syndicate in:

- Supervision Mode
