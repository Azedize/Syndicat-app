PHASE 6 — EXAMPLE PROBLEM DETECTION
===================================

Example:

TRAVAUX

Problem:

If Super Admin can create a building renovation project, this is wrong.

Why?

The project belongs to a specific residence.

Correct role:

* President
* Syndic Admin
* Maintenance Manager

Incorrect role:

* Tenant
* Property Owner
* Super Admin

---

PRESTATAIRES

Problem:

If a Tenant can edit supplier contracts, this is wrong.

Correct role:

* President
* Treasurer
* Syndic Admin

---

SINISTRES

Problem:

If financial staff can close incidents without validation, this is wrong.

Correct role:

* Maintenance
* President

---

PARKING

Problem:

If all residents can edit all vehicles, this is wrong.

They should only manage their own vehicles.

---

ASSEMBLÉES

Problem:

Tenants should not create official assemblies.

Only governance roles should.

---

VOTES

Problem:

Only eligible owners should vote.

Prevent duplicate votes.

---

RÉCLAMATIONS

Problem:

A resident should only see his own complaints.

---

COTISATIONS

Problem:

Owners can see their own contributions.

They should never see other owners' financial data.

---

CHARGES

Problem:

Tenants should not access building accounting.

---

LOTS

Problem:

Residents should not edit lot ownership records.

---

RÉSIDENTS

Problem:

Personal information leakage between residents.
