You are a Senior Product Owner, Enterprise Document Management Expert, UX Architect, SaaS Architect, and Moroccan Condominium Management Expert.

Mission:

Analyze and redesign the complete Document Creation Workflow.

Current Problem:

The current document module behaves like a "black box".

When a user creates a document:

* The system automatically fills information.
* The user does not know where the data comes from.
* The user cannot see the template structure.
* The user cannot see which fields are dynamic.
* The user cannot preview the document before generation.
* The user cannot understand how the document is built.

This creates confusion and reduces trust in the system.
